# Wealth

Personal wealth dashboard: net worth, stocks/ETFs, mutual funds, EPF, crypto, debt, credit score, insurance.

Setup
1. Supabase: SQL Editor, run `setup.sql` once.
2. Settings, Pages: deploy from branch `main`, folder `/ (root)`.
3. Open the site, create an account (same Supabase project as `classic/`), then Import your Groww files.

`classic/` is the previous dashboard, unchanged.
